# TODO App

A simple, clean TODO application built with vanilla HTML, CSS, and JavaScript. No build tools or frameworks required.

## Features

- **Add tasks** - Type a task and press Enter or click "Add"
- **Mark tasks complete** - Click the checkbox to toggle completion
- **Delete tasks** - Hover over a task and click the X button to remove it
- **Filter tasks** - View All, Active, or Completed tasks
- **Persistent storage** - Tasks are saved to localStorage and persist across browser sessions
- **Responsive design** - Works on desktop and mobile devices

## How to Use

1. Open `index.html` in any modern web browser
2. Type a task in the input field and press Enter (or click "Add")
3. Click the checkbox next to a task to mark it as complete
4. Hover over a task and click the X button to delete it
5. Use the filter buttons (All / Active / Completed) to view specific tasks

No server, installation, or build step is needed. Just open the HTML file directly in your browser.
